# The Vine Inn Cumnor – Intimate Weddings & Private Hire Website

Static website for promoting exclusive hire of The Vine Inn, Cumnor (Oxfordshire) for intimate weddings and private events.

## Live site (once GitHub Pages is enabled)

`https://rhodirish-afk.github.io/vine-inn-cumnor-weddings/`

## Features

- Fully responsive, mobile-first design
- Semantic HTML5 + Tailwind CSS (CDN – zero build)
- Accessibility foundations (skip link, focus styles, reduced-motion, labels)
- CTA: Bookings available from August 2026 · Now taking 2027 enquiries
- Full sections: Hero, About, Weddings, Private Hire, Packages, Facilities, Reviews, Location, Enquire form
- Official gallery images + selected 5-star reviews
- Suggested package pricing from project brief

## Enable GitHub Pages

Repo Settings → Pages → Source: Deploy from branch `main` / root → Save.
